# Rotating Image Gallery

An interactive 3D image carousel and mobile card deck built using HTML, CSS, and JavaScript.

## Features
- 3D rotating carousel effect
- Responsive desktop and mobile layouts
- Touch gesture interaction
- Dynamic card deck transitions
- CSS transform and perspective effects

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Practiced
- CSS 3D transforms
- DOM manipulation
- Touch event handling
- Responsive design
- State-based UI interactions
